How I work

Pointing out what's broken is only half a job. The other half is pointing at what works instead.

01

Scope small

Scope small enough to finish. If a project can't be completed at the size I've set, the size is wrong.

02

Test the core

Test the core before building on it. The central loop gets proven before anything is stacked on top.

03

Write it down

Write down what happened, including when it didn't work.
